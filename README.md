# FileBridge Pro — Desktop File Transfer & Automation Utility

A Python-based desktop application designed for structured file routing, bridging, and management, equipped with an automated PyInstaller packaging pipeline.

## System Components
- **filebridge_pro.py**: Core desktop application logic and file verification routing.
- **build_exe.bat**: Automated Windows build batch toolchain.
- **FileBridgePro.spec**: PyInstaller standalone executable specification.
